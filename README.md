# AtliQ Hospitality Analysis Dashboard

## Project Overview

This Power BI dashboard analyzes hospitality business performance across multiple properties and cities.

The dashboard helps management monitor:

- Revenue performance
- Occupancy rates
- ADR (Average Daily Rate)
- RevPAR (Revenue Per Available Room)
- Booking trends
- Property performance

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key Business Metrics

- Revenue
- Occupancy %
- ADR
- RevPAR
- Realization %
- Booking Performance

## Key Insights

- Identified top-performing properties.
- Analyzed occupancy and revenue trends.
- Compared city-level hotel performance.
- Generated insights for revenue optimization.
